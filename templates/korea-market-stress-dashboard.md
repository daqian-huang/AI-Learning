# 韩国市场压力监控模板

> 用途：把韩国股市、外汇、资金流、杠杆与波动率指标放在同一张表里，用于判断是否只是普通回调，还是正在演化为流动性压力或杠杆踩踏。

## 核心监控数据

| 数据 | 作用 | 观察重点 |
| --- | --- | --- |
| KOSPI 涨跌幅 | 市场压力 | 判断韩国权益市场整体风险偏好是否快速转弱。 |
| 三星电子涨跌 | 权重股压力 | 观察指数最大权重股是否拖累大盘，并验证半导体主线是否退潮。 |
| SK Hynix 涨跌 | AI 存储核心压力 | 观察 HBM、AI 存储与数据中心链条是否出现集中抛压。 |
| 韩元 USD/KRW | 资本外逃信号 | USD/KRW 快速上行通常代表韩元走弱，需要结合外资流向确认。 |
| 外资净买卖 | 谁在撤退 | 判断海外资金是否正在主动降低韩国权益敞口。 |
| 机构净买卖 | 承接力量 | 判断本土机构是否提供稳定买盘，还是与外资同步撤退。 |
| 散户净买卖 | 是否继续加杠杆接盘 | 观察散户是否在下跌中持续买入，并结合融资余额判断风险。 |
| 融资余额 | 杠杆总量 | 跟踪市场内融资交易规模，识别潜在强平燃料。 |
| 强制平仓金额 | 是否进入爆仓链 | 若强平金额放大且指数继续下跌，说明风险可能从价格下跌转向杠杆去化。 |
| 单股杠杆 ETF 资金流 | 杠杆放大器 | 观察杠杆产品是否继续吸收资金，或出现被动去杠杆压力。 |
| 韩国国债收益率 | 信用/流动性风险 | 收益率快速上行可能反映流动性收紧或信用风险重新定价。 |
| V-KOSPI | 恐慌程度 | 衡量期权市场隐含波动率，确认是否进入恐慌交易环境。 |

## 快速判读框架

1. **普通回调**：KOSPI 下跌，但 USD/KRW 稳定、外资没有持续净卖出、V-KOSPI 仅温和上行。
2. **资金撤退**：KOSPI 下跌叠加 USD/KRW 上行，外资连续净卖出，机构承接不足。
3. **杠杆踩踏**：融资余额前期偏高，强制平仓金额放大，散户仍在净买入或杠杆 ETF 继续吸金。
4. **系统性压力**：股市下跌、韩元走弱、韩国国债收益率上行、V-KOSPI 跳升同时出现。

## 使用建议

- 同时看“价格变化”和“资金流变化”，避免只凭指数涨跌判断风险。
- 对外资、机构、散户资金流使用同一口径和同一交易所来源，减少数据口径误差。
- 将融资余额和强制平仓金额做成时间序列，重点看变化速度而不是单日绝对值。
- 该模板仅用于研究和风险监控，不构成投资建议。
